## Required Content in the Video
The video must include, with screen share + your voice-over:

1. **Project Name** – "FitTrack AI"
2. **Purpose of the Project** – why manual workout tracking is a problem,
   and what this backend solves (see Phase 1)
3. **Use / Benefits** – secure centralized workout data, AI-personalized
   recommendations, fitness insights from stats
4. **Execution / Working Process**
   - Show the folder structure and briefly explain MVC layers
   - Start the server (`npm run dev`) and show it connect to MongoDB
   - Walk through Postman: Register → Login → Add Workout → Get Workouts →
     Search → Update → Delete → AI Workout Recommendation → AI Fitness
     Insights
5. **Final Output** – show a successful AI recommendation and insight
   response as the closing result

## Suggested Script Outline (5–8 minutes)
1. (0:00–0:30) Intro — name, team, project title, one-line purpose
2. (0:30–1:30) Problem/solution recap (from Phase 1)
3. (1:30–3:00) Architecture walkthrough (from Phase 3 diagram description)
4. (3:00–6:30) Live Postman demo of every endpoint in the order listed in
   Phase 6
5. (6:30–7:30) Recap of outcomes + possible future extensions (nutrition
   tracking, BMI, wearables, reminders, dashboards)
6. (7:30–end) Close
